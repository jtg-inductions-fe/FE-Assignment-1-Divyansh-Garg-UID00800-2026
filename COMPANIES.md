# Companies Component

## Overview

The Companies component has been implemented across HTML and SCSS files.

## File Structure

```text
src/
└── styles/
    └── components/
        ├── _companies.scss
    └── layout/
        |── _site-comapanies.scss

index.html
```

## Implementation

### HTML

The companies markup has been added to:

`index.html`

The HTML contains the structure for the companies and the static img and the div comoponent which is shown on both sides of the companies section.

### SCSS

The companies styles are separated into two component files:

#### `_companies.scss`

`src/styles/components/_companies.scss`

Contains the styles responsible for the overall companies layout and appearance.

#### `_site-companies.scss`

`src/styles/components/_site-companies.scss`

Contains the styling required for the static images and div and also the main companies styling element.

## Notes

The companies follows the project's component-based SCSS architecture.
